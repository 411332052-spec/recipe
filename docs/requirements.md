# 需求說明

## 這是什麼
一個在我自己電腦上執行的 Discord agent。只要它開著，我 Discord Server 裡指定頻道的任何人傳一張食材照片進來，它就會判斷食材、推薦料理、生成食譜、建檔，再回覆上傳者。agent 關掉就不處理。

## 誰會用
我自己的 Discord Server 裡、那個指定頻道的任何人，用手機或電腦都可以傳。

## 使用的流程
1. 有人在頻道裡傳一張食材照片
2. agent 收到，先回一個「處理中」的提示
3. agent 判斷：是不是食材、辨識出哪些食材與配料、推薦適合的料理食譜(包含食材清單與詳細步驟)
4. agent 把結果記下來、把照片存起來
5. agent 回覆上傳者辨識到的食材，並附上推薦的料理與食譜內容

## 要記錄的內容（存成一個可以一直往下加的 Excel 檔）
- 日期時間
- 上傳者
- 是否為食材
- 辨識到的食材清單
- 推薦料理名稱
- 完整食譜與步驟
- 照片存放位置

照片另外存進一個資料夾，檔名用「日期時間 + 主要食材簡稱」。

## 不是食材的時候
一樣要回覆上傳者「你傳的不是食材，是某某東西」，用 agent 判斷出來的東西說明。這種照片也要建檔、也要存，只是「是否為食材」那欄寫「否」，辨識到的食材清單欄寫「它到底是什麼，不是食材」（例如「貓，不是食材」），推薦料理名稱欄寫「無」，完整食譜與步驟欄留空。

## 畫面上 / 回覆上要有
- 收到時先有「處理中」的提示
- 處理完回覆：辨識出的食材清單、推薦料理名稱、詳細食譜與步驟(若不是食材則說明是甚麼)

## 不需要的
- 註冊、登入
- 長時間、大規模的雲端服務（這就是一支開著才會動的本機程式）
- （其他你確定不要的）

## 技術上我知道的
- 用 Python 3.12 + uv（課前已經裝好；實務上也可以用別的語言，這裡先固定）
- 照片用 `claude -p` 在我這台電腦上處理
- Discord 用 Gateway（bot）模式，不需要 ngrok
- 紀錄存成一個可以持續往下加的 Excel 檔
- 設定放在 `.env`：`DISCORD_TOKEN`、`CHANNEL_ID`、`CLAUDE_MODEL`、`DATA_DIR`

## 做事的順序
1. 先把 agent 做好，所有防護都開著，自己測到正常
2. 之後（上課時）再把防護全部關掉做對照
