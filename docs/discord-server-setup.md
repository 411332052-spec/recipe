# Discord Server 設定步驟

這份文件帶你做三件事：

1. 建立你自己的 Discord Server（伺服器）
2. 建立給 agent 用的頻道，並拿到 `CHANNEL_ID`
3. 產生邀請連結，讓同組同學加入

> 做完這份，再做 `docs/discord-bot-setup.md`（建立 bot、邀請它進你的 Server）。
>
> 畫面說明以 Windows 版 Discord 桌面程式為主，用網頁版（discord.com/app）也一樣。Discord 偶爾會改版，如果按鈕名稱跟這裡不完全一樣，找意思最接近的那一個。括號裡的英文是英文介面的名稱。

---

## 一、建立你自己的 Server

1. 打開 Discord，登入你的帳號。
2. 看畫面**最左邊**那一排圓形圖示（這是你加入的所有 Server）。拉到最下面，找到一個 **「＋」** 圓形按鈕（「新增伺服器」，Add a Server），點它。
3. 跳出視窗，選 **「建立我的」**（Create My Own）。
4. 下一頁問你要用在哪裡，選 **「為我和我的朋友」**（For me and my friends）。
5. 在「伺服器名稱」欄位輸入名字，例如 `食譜機器人測試`。其他不用動。
6. 按右下角 **「建立」**（Create）。

做完後，左邊那排會多一個你的 Server 圖示，右邊會看到它預設的頻道，例如 `#一般`（#general）。

---

## 二、建立給 agent 用的頻道

agent 只會聽**一個**頻道，所以要另外開一個專用的。

1. 在 Server 的頻道清單中，找到「文字頻道」（Text Channels）這一行，把滑鼠移到它右邊，點出現的 **「＋」**（建立頻道，Create Channel）。
2. 「頻道類型」選 **「文字」**（Text）。
3. 「頻道名稱」輸入 `食譜`（或 `recipe`）。Discord 會自動轉成小寫並用連字號。
4. **不要**打開「私人頻道」（Private Channel）的開關。之後要讓同學進來傳照片，所以頻道要是公開的。
5. 按 **「建立頻道」**（Create Channel）。

左邊頻道清單會多出 `#食譜`。

---

## 三、拿到 CHANNEL_ID

`CHANNEL_ID` 是這個頻道的一串數字編號。Discord 預設看不到，要先打開「開發者模式」。

### 3-1 打開開發者模式（只要做一次）

1. 看畫面**左下角**你的頭像旁邊，點 **齒輪圖示**（使用者設定，User Settings）。
2. 左邊選單往下找到 **「進階」**（Advanced），點它。
3. 把 **「開發者模式」**（Developer Mode）的開關打開（變成綠色）。
4. 按右上角的 **ESC** 或 **X** 關掉設定。

### 3-2 複製頻道 ID

1. 在頻道清單中，對 `#食譜` 按**滑鼠右鍵**。
2. 在選單最下面點 **「複製頻道 ID」**（Copy Channel ID）。
3. 打開**記事本**，按 `Ctrl + V` 貼上，會看到一串約 18～19 位的數字，例如 `123456789012345678`。
4. 先留著，之後會寫進 `.env` 的 `CHANNEL_ID`（做法在 `docs/discord-bot-setup.md` 最後一節）。

> `CHANNEL_ID` 不是密碼，但也沒必要貼到公開的地方。

---

## 四、產生邀請連結，讓同學加入

> **先看這個提醒：** 任何拿到連結的人都能加入你的 Server，而且之後可以在 `#食譜` 傳照片。每傳一次，agent 就用掉一次**你自己的 Claude 額度**（見 `docs/architecture.md` 第 13 節）。所以連結要設「有效期限」和「使用次數」，不要發到公開的地方。

1. 在左邊頻道清單的**最上面**，點你的 **Server 名稱**（例如「食譜機器人測試」）。
2. 在跳出的選單中選 **「邀請朋友」**（Invite People）。
3. 跳出的視窗最下面，會看到一條連結（`https://discord.gg/xxxx`）。**先不要複製**，按視窗下方的 **「編輯邀請連結」**（Edit invite link，一個小齒輪或文字連結）。
4. 設定：
   - **「此連結到期於」**（Expire after）：選 **7 天**（測完就失效）。
   - **「最大使用次數」**（Max number of uses）：選你同組人數的數字，例如 **5 次**。
   - **「授予臨時成員資格」**（Grant temporary membership）：**不要打開**。打開的話，同學離線後會被踢出。
5. 按 **「產生新連結」**（Generate a New Link）。
6. 按連結旁的 **「複製」**（Copy）。
7. 貼給同組同學（用你們私下的群組，不要貼在公開的地方）。

### 同學要怎麼加入

1. 同學點連結。
2. 如果他們的電腦有 Discord，會跳出邀請畫面；按 **「接受邀請」**（Accept Invite）。
3. 加入後，他們會在左邊看到你的 Server，進入 `#食譜` 就可以傳照片了。

### 如果想收回連結

點 Server 名稱 → **「伺服器設定」**（Server Settings）→ **「邀請」**（Invites）→ 找到那條連結，點右邊的 **X** 刪除。

---

## 五、做完後確認

- [ ] 左邊有你的 Server。
- [ ] Server 裡有 `#食譜` 頻道。
- [ ] 你已經複製下 `CHANNEL_ID`（一串數字）並暫存在記事本。
- [ ] 邀請連結有設到期日與使用次數。
